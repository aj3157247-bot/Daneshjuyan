سیستم لینک کوتاه دانشجویان

فایل‌های ZIP را با همان مسیر در مخزن جایگزین کنید.
این سیستم از اتصال فعلی Cloudflare D1 با نام DB استفاده می‌کند و جدول short_links را در اولین درخواست ایجاد می‌کند.
اگر کاربر مجوز ساخت جدول در D1 نداشته باشد، لازم است دستور زیر را در D1 اجرا کنید:
CREATE TABLE IF NOT EXISTS short_links (code TEXT PRIMARY KEY, target TEXT NOT NULL UNIQUE, created_at TEXT DEFAULT CURRENT_TIMESTAMP);

لینک‌های اشتراک‌گذاری جدید به شکل /s/xxxxxxxxxx ساخته می‌شوند. لینک‌های قبلی /share?... همچنان کار می‌کنند.
لینک‌های خصوصی هیچ مجوز اضافی نمی‌دهند؛ دسترسی در API اصلی بررسی می‌شود.
اگر پایگاه داده قطع باشد، لینک اصلی به اشتراک گذاشته می‌شود.
برای تست: پس از انتشار یک فایل یا نوت را اشتراک بگذارید، سپس لینک را در مرورگر ناشناس باز کنید.
توجه: این تغییر لینک‌های اشتراک‌گذاری سایت را کوتاه می‌کند؛ تمام مسیرهای API، فایل‌های استاتیک و مسیرهای فنی را تغییر نمی‌دهد تا سایت خراب نشود.
