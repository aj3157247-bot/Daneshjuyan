# اپلیکیشن اندروید دانشجویان
این ZIP **پروژه Android Studio** است، نه APK آماده.

- بخش آنلاین: WebView سایت `https://daneshjuyan.pages.dev/`
- بخش آفلاین: انتخاب PDF از حافظه، استخراج متن و OCR فارسی، و ذخیره TXT و DOCX.
- فایل PDF برای پردازش به سرور فرستاده نمی‌شود.
- هنگام **ساخت APK**، Gradle مدل `fas.traineddata` را دریافت و در APK قرار می‌دهد؛ بنابراین پس از نصب، OCR به اینترنت احتیاج ندارد.
- OCR برای صفحات اسکن‌شده یا صفحاتی که متن استخراجی بسیار کم/خراب است فعال می‌شود؛ ممکن است PDFهای دارای نگاشت فونت خراب ولی متن طولانی همچنان نیازمند OCR اجباری باشند.
- DOCX شامل متن راست‌به‌چپ است؛ قالب‌بندی پیچیده PDF حفظ نمی‌شود.
- این پروژه در این محیط کامپایل و روی گوشی آزمایش نشده است؛ سازگاری وابستگی‌ها و مجوزهای فایل در Android Studio بررسی شود.

## ساخت
1. ZIP را استخراج و پوشه `Daneshjuyan-Android` را در Android Studio باز کنید.
2. اینترنت را برای اولین Gradle Sync و دریافت مدل OCR روشن کنید.
3. از Build > Build APK(s) فایل APK بسازید.
4. بعد از نصب، اینترنت گوشی را خاموش و ابزار آفلاین را امتحان کنید.

**نکته:** فایل‌های سایت Cloudflare Pages دست‌نخورده باقی مانده‌اند.
