# دانشجویان — شروع پروژه Cloudflare

این بسته، فرانت‌اند موجود را در مسیر درست `public/` قرار می‌دهد و پایه‌ی پروژه را برای Cloudflare Pages آماده می‌کند.

## چه چیزی آماده است؟
- صفحه فعلی سایت داخل `public/`
- مسیر آزمایشی `GET /api/health` برای بررسی اتصال
- طرح اولیه پایگاه داده D1 در `schema.sql`
- پیکربندی اولیه Pages در `wrangler.toml`
- ساختار داده برای دانشگاه، رشته، سمستر، صنف‌های پویا، عضویت تأییدشده، منابع، گروه‌های گفتگو، عکس‌های یادگاری خصوصی و گزارش‌ها

## چه چیزی هنوز آماده نیست؟
این بسته هنوز سیستم کامل ورود/ثبت‌نام، مدیریت نشست امن، APIهای محتوا و چت، بارگذاری فایل به R2، کنترل دسترسی نهایی یا پنل مدیریت اجرایی ندارد. تا پیاده‌سازی و آزمایش این بخش‌ها، اطلاعات واقعی دانشجویان و عکس‌های خصوصی را وارد نکنید. طرح SQL به‌تنهایی بک‌اند فعال نیست.

## انتشار در Cloudflare Pages
- Build command: خالی (برای سایت استاتیک)
- Build output directory: `public`
- فایل `wrangler.toml` در ریشه مخزن است.
- پس از ایجاد D1 و R2 در Cloudflare، مقادیر ID/نام و bindingها را در تنظیمات پروژه تنظیم کنید.
- پس از انتشار، مسیر `/api/health` را باز کنید؛ تا وقتی D1/R2 را تنظیم نکرده‌اید، وضعیت `not_configured` طبیعی است.

## D1
از Cloudflare Dashboard یک D1 database بسازید و محتوای `schema.sql` را در بخش Console اجرا کنید. پیش از استفاده عمومی، migrationها را نسخه‌بندی و آزمایش کنید.

## امنیت و گالری عکس
گالری عکس باید فقط از طریق API دارای احراز هویت و بررسی عضویت همان صنف ارائه شود؛ URL مستقیم عمومی برای عکس‌ها نسازید. عکس‌ها باید در R2 خصوصی بمانند و دانلود از مسیر Worker/Pages Function پس از بررسی دسترسی انجام شود.
