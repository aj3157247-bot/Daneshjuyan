# دانشجویان — نسخه Cloudflare Pages + D1

این مخزن یک پایه اجرایی برای پلتفرم دانشجویان افغانستان است. فرانت‌اند فارسی/دری و واکنش‌گرا است و APIهای Cloudflare Pages Functions برای ساخت صفحه/گروه خصوصی، ورود با رمز، ذخیره نوت و ذخیره پیام متنی دارد.

## قابلیت‌هایی که در این نسخه واقعاً کار می‌کنند
- فهرست عمومی صفحه‌ها و گروه‌ها و جستجو در آن‌ها
- ساخت صفحه درسی یا گروه گفتگو با نام دانشگاه، رشته، سمستر، نوبت و رمز
- هش‌کردن رمز دسترسی با PBKDF2 و ایجاد نشست امضاشده در کوکی HttpOnly
- کنترل نشست در APIهای محتوای خصوصی
- ذخیره و دریافت نوت‌های متنی و پیام‌های متنی از D1
- کپی نوت با یک دکمه و رابط سازگار با موبایل
- endpoint سلامت `/api/health`

## چه چیزهایی هنوز تکمیل نشده‌اند
این پروژه هنوز نسخه نهایی یک شبکه اجتماعی بزرگ نیست. ثبت‌نام/ورود با حساب کاربری، تأیید عضویت دانشجو، پنل مدیر اصلی، مدیریت ساختار دانشگاه/رشته/سمستر/صنف به شکل رابطه‌ای، آپلود فایل و عکس، گالری یادگاری، پسند/نظر/گزارش محتوا، چندزبانه کامل و چت زنده هنوز نیازمند پیاده‌سازی و آزمایش‌اند. بخش‌های مربوط به فایل/عکس را تا زمانی که R2 یا فضای سازگار امن وصل نشده، فعال فرض نکنید.

## Cloudflare
1. در Pages پروژه، Build output directory باید `public` باشد. چون فایل‌های API داخل `functions/` هستند، آن پوشه را حذف نکنید.
2. Binding دیتابیس D1 باید نام `DB` داشته باشد و به دیتابیس `daneshjuyan` متصل باشد.
3. در Settings → Variables and secrets یک Secret با نام دقیق `SESSION_SECRET` بسازید. مقدار آن را در GitHub یا کد قرار ندهید.
4. در D1 Console فایل `schema.sql` را اجرا کنید. اجرای دوباره امن است چون جدول‌ها با `IF NOT EXISTS` ساخته می‌شوند.
5. پس از Deploy، `/api/health` را باز کنید. `databaseStatus` باید `connected` و `schemaStatus` باید `ready` باشد.

## انتشار از GitHub
فایل‌ها را در مخزن فعلی جایگزین کنید و Commit کنید. Cloudflare Pages با اتصال GitHub باید خودکار Deploy کند. پس از هر تغییر، صفحه Deployments را بررسی کنید و سپس `/api/health` را آزمایش کنید.

## نکات امنیتی و عملیاتی
- رمز صفحه را با افراد مورداعتماد شریک کنید؛ این روش هنوز جایگزین حساب کاربری و عضویت تأییدشده نیست.
- برای انتشار گسترده، rate limiting، کنترل دسترسی مبتنی بر کاربر، ابزار گزارش/حذف، سیاست حریم خصوصی، محدودیت اندازه درخواست و آزمون امنیتی لازم است.
- فایل `server.js` برای اجرای محلی Node است؛ Cloudflare Pages Functions به‌صورت مستقل از آن اجرا می‌شود.
