# دانشجویان — طرح ساده صفحه‌ها و گروه‌ها

این نسخه رابط کاربری را مطابق خواسته ساده‌تر می‌کند:
- صفحه اصلی فقط معرفی کوتاه، فهرست صفحه‌ها/گروه‌ها و دکمه ساخت دارد.
- هنگام ساخت، کاربر نام صفحه/گروه، نام پوهنتون، رشته، سمستر، نوبت و رمز را خودش وارد می‌کند.
- همه می‌توانند کارت صفحه‌ها و گروه‌ها را ببینند؛ محتوا پس از واردکردن رمز نمایش داده می‌شود.
- صفحه‌ها و گروه‌ها به‌صورت دو دسته جدا نمایش داده می‌شوند.
- در نمونه نمایشی، بعد از واردکردن صحیح رمز، دسترسی در همان مرورگر به خاطر سپرده می‌شود.

## مهم: محدودیت امنیتی نمونه
این فقط نمونه نمایشی frontend است. اطلاعات و رمزها در `localStorage` مرورگر ذخیره می‌شوند؛ این روش امن نیست و هرگز نباید برای صنف واقعی یا اطلاعات خصوصی استفاده شود. در نسخه واقعی باید:
1. رمز در سرور هش شود، نه در مرورگر.
2. ورود و دسترسی با Backend بررسی شود.
3. محتوای خصوصی فقط پس از بررسی رمز/عضویت از API تحویل شود.
4. برای صفحه‌ها و گروه‌ها پایگاه داده D1 و برای فایل‌ها R2 استفاده شود.
