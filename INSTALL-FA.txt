اصلاح رابط گروه (طرح A + C)

فایل‌های تغییرکرده:
- public/app.js
- public/styles.css

روش جایگزینی:
1) در مخزن GitHub پروژه Daneshjuyan پوشه public را باز کن.
2) فایل app.js را باز و Edit کن؛ محتوای فایل public/app.js داخل این ZIP را جایگزین کامل محتوای فعلی کن و Commit کن.
3) همین کار را برای public/styles.css انجام بده.
4) منتظر بمان Cloudflare Pages انتشار را تمام کند، سپس سایت را با Refresh کامل باز کن.

این اصلاح در گروه موبایل، صفحه گروه را تمام‌صفحه می‌کند، تب‌های نوت/فایل/خاطرات و انتخاب سمستر را پنهان می‌کند، پیام‌ها را در ناحیه قابل‌اسکرول می‌گذارد و کادر ارسال را پایین نگه می‌دارد. صفحه‌های درسی قابلیت‌های قبلی خود را نگه می‌دارند.

نکته مهم: نام فرستنده از فیلدهای authorName/displayName/firstName/surname/author در پاسخ API خوانده می‌شود. اگر API فعلی نام حساب را برنگرداند، رابط به‌تنهایی نمی‌تواند نام واقعی را ایجاد کند؛ این ZIP تغییری در API یا پایگاه داده نمی‌دهد.
