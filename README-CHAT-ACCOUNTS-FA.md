# به‌روزرسانی حساب دانشجویی و چت گروه‌ها

این نسخه ظاهر گروه را به اتاق گفتگوی واقعی نزدیک‌تر می‌کند و حساب دانشجویی با نام، تخلص و رمز اضافه می‌کند. نام دانشجو در پیام‌ها خودکار نمایش داده می‌شود؛ فرستنده دیگر نمی‌تواند نام دلخواه شخص دیگری را برای پیام انتخاب کند. کد همچنان از D1 استفاده می‌کند و به R2 وابسته نیست.

## قبل از انتشار
1. فایل `MIGRATION-STUDENT-CHAT.sql` را باز کن.
2. هر دستور را جداگانه در D1 Console دیتابیس `daneshjuyan` اجرا کن: اول `CREATE TABLE`, بعد `ALTER TABLE`, بعد `CREATE INDEX`.
3. اگر دستور `ALTER TABLE` پیام `duplicate column name: author_id` داد، یعنی ستون قبلاً وجود دارد؛ فقط همان دستور را رد کن و دستور بعدی را اجرا کن.
4. همه فایل‌های این ZIP را در ریشه مخزن GitHub پروژه جایگزین/اضافه کن، سپس Commit کن تا Cloudflare Pages خودکار Deploy کند. `SESSION_SECRET` و binding `DB` را حذف یا تغییر نده.
5. بعد از انتشار سایت را تازه‌سازی کن، روی «حساب دانشجویی» بزن، حساب بساز، سپس وارد گروه شو و گفتگو کن.

این migration جدول‌ها و پیام‌های قبلی را حذف نمی‌کند. پیام‌های قدیمی که نویسنده ندارند با نام «عضو قبلی» دیده می‌شوند.
