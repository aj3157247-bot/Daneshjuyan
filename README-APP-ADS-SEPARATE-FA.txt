مدیریت مستقل تبلیغات سایت و اپلیکیشن دانشجویان

۱. فایل‌های ZIP را در همان مسیرها در مخزن GitHub قرار دهید.
۲. در Cloudflare D1 (دیتابیس Production) محتوای MIGRATION-APP-ADS-SEPARATE.sql را فقط یک بار اجرا کنید.
۳. سایت Cloudflare Pages را منتشر کنید.
۴. وارد /admin/analytics شوید: بخش «تبلیغات سایت» قدیمی دست نخورده است و بخش «تبلیغات اپلیکیشن» جدا اضافه شده.
۵. تبلیغ اپلیکیشن اضافه کنید؛ برای تصاویر از لینک HTTPS عمومی استفاده کنید.
۶. با GitHub Actions یک APK جدید بسازید و نصب کنید. APK قدیمی هنوز API تبلیغات سایت را می‌خواند.
۷. در حالت آنلاین تبلیغات اپلیکیشن بارگذاری و در حافظه گوشی کش می‌شوند؛ پس از اولین دریافت موفق، بدون اینترنت نیز آخرین تبلیغات و تصاویر دانلودشده قابل مشاهده هستند.

جداسازی داده‌ها: جدول ads فقط سایت؛ جدول app_ads فقط اپلیکیشن. API اپلیکیشن /api/app-ads است.
هیچ تغییری در ثبت‌نام، مدیریت کاربران، گروه‌ها، فایل‌ها، OCR و دیگر بخش‌های سایت داده نشده است.
هشدار: این تغییرات در محیط حاضر روی Cloudflare و Android اجرا و تست نشده‌اند.
