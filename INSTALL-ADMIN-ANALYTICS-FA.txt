تغییرات مدیریت و آمار ترافیک دانشجویان

۱) این ZIP نسخه کامل پروژه است؛ محتویات پوشه Daneshjuyan-main را در مخزن GitHub جایگزین کن.
۲) لینک «مدیریت» از بالای سایت حذف شده است.
۳) صفحه مدیریت جدید در مسیر /admin/analytics قرار دارد. مسیر قدیمی /admin.html به مسیر جدید منتقل می‌شود.
۴) داشبورد تعداد بازدیدهای ثبت‌شده در tracker سایت (کل، امروز، بازدیدکنندگان یکتا و نمودار ۱۴ روزه) را نشان می‌دهد. این اعداد فقط رویدادهای ثبت‌شده توسط سایت هستند و به معنی همه درخواست‌های شبکه/CDN نیستند. برای کل درخواست‌های HTTP واقعی از Cloudflare Dashboard > Analytics استفاده کن؛ راهنما: https://developers.cloudflare.com/pages/how-to/web-analytics/
۵) پس از جایگزینی، منتظر انتشار سبز Cloudflare Pages بمان. اگر جدول site_events در D1 موجود نباشد، آمار API خطا می‌دهد و باید migration موجود پروژه اجرا شده باشد.
