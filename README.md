# دانشجویان

قالب اولیه و واکنش‌گرای یک وب‌سایت منابع درسی دانشگاه‌های افغانستان.

## اجرا
فایل `index.html` را باز کنید یا این پوشه را در یک سرویس میزبانی استاتیک مانند Cloudflare Pages / GitHub Pages منتشر کنید.

## فایل‌ها
- `index.html` ساختار صفحه
- `styles.css` طراحی، رنگ‌بندی و واکنش‌گرایی
- `app.js` داده‌های نمونه، جستجو، فیلترها، نمایش رشته و سمسترها و فرم پیشنهاد منبع

## نکته مهم
این نسخه فرانت‌اند و نمونه اولیه است. دانشگاه‌ها، رشته‌ها، مضامین و منابع داخل `app.js` داده‌های نمونه‌اند و کامل یا تأییدشده رسمی نیستند. فرم پیشنهاد منبع فقط اطلاعات را در `localStorage` همان مرورگر ذخیره می‌کند؛ فایل واقعاً آپلود نمی‌شود و مدیر مرکزی وجود ندارد. برای راه‌اندازی عمومی باید بک‌اند، پایگاه داده، احراز هویت، فضای ذخیره‌سازی فایل، پنل مدیریت و بررسی حقوق نشر منابع اضافه شود. قبل از انتشار عمومی، اطلاعات رسمی دانشگاه‌ها و منابع را بررسی و تکمیل کنید.
